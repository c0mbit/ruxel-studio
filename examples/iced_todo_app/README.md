# Iced To-Do List Application — Ruxel Studio Example

This example demonstrates a complete, responsive To-Do application built with the [Iced GUI framework](https://github.com/iced-rs/iced) (v0.13) and visually designed using **Ruxel Studio**.

---

## Architecture Overview

- **`app.rux`**: The single source of truth for the visual scene graph (AST). Defines the window parameters, layout hierarchy (`v_box`, `h_box`), widgets (`text_input`, `button`, `checkbox`, `label`), styles, and event triggers.
- **`src/ui_generated.rs`**: Clean, zero-comment Rust code automatically generated by Ruxel Studio. Declares `AppState`, `UiMessage`, `UiHandler`, and the pure `view(&AppState)` function.
- **`src/controller.rs`**: Developer-owned business logic implementing `UiHandler`. Ruxel Studio uses AST-level non-destructive merging, so developer logic in this file is never overwritten during visual exports.
- **`src/main.rs`**: Native application entry point running `iced::application`.

---

## Opening in Ruxel Studio

1. Open this repository or the `examples/iced_todo_app/` folder in VS Code with the **Ruxel Studio** extension installed.
2. In the Explorer pane, click `app.rux`. VS Code will open the file in the **Ruxel Visual Editor**.
3. The interactive canvas will render the To-Do list preview with interactive component selection and properties editing in the Inspector pane.

---

## Testing Bidirectional Sync

Ruxel Studio features lossless, real-time bidirectional synchronization between the visual canvas and Rust code:

### 1. Visual-to-Code Sync
1. In the Ruxel Visual Editor, click the `"Add Task"` button or `"Ruxel Tasks"` header on the canvas.
2. In the React Inspector pane on the right, change the header text to `"My Sprint Tasks"`.
3. Press `Ctrl+S` or execute the command `Ruxel: Generate & Export Rust Code (ui_generated.rs & controller.rs)`.
4. Open `src/ui_generated.rs`: observe that the `text("...")` call has been cleanly updated.
5. Inspect `src/controller.rs`: observe that all custom handler logic remains completely intact.

### 2. Code-to-Visual (Reverse Parsing)
1. Open `src/ui_generated.rs` in a side-by-side editor with `app.rux`.
2. Locate the `button(text("Clear Completed"))` in the `view()` function.
3. Edit the label to `button(text("Purge Done"))` and save the file.
4. Watch the `rux-daemon` background file watcher detect the save, run the AST reverse-parser, and patch `app.rux` without modifying any other nodes or formatting.
5. The visual canvas immediately updates to reflect the new button label.
